拿到七段信息后，逐段对一遍：

1. **账号**：@ 前面的登录名
2. **密码**：首次登录用
3. **绑定邮箱**：账号绑的那个邮箱地址
4. **绑定邮箱密码**：有这段，说明邮箱能自己登
5. **token**：登录令牌，部分工具和群控软件用它免密登录
6. **2FA密钥**：一串大写字母，形如 `YE47BHBT2YDDPM5L`
7. **备用码**：2FA 的一次性恢复码

邮箱这一步容易卡住。带邮箱密码的，去 mail.tm 这类邮箱站登录；不带邮箱密码的，看邮箱 @ 后面那段后缀，比如 `xxx@1secmail.com` 就去 1secmail.com 输地址查收，这类临时邮箱不需要密码。2FA 密钥拿去 2fa.fun 输入，生成 6 位动态码，登录时填进去。
